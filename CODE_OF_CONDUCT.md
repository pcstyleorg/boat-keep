# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good faith, and keep it about the work. Harassment and personal attacks aren't welcome anywhere in the project.

To report a problem, message the maintainer privately on [GitHub](https://github.com/pc-style). Reports stay confidential.
